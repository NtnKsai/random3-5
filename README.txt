โปรแกรมสุ่ม RANDOMIZER TOOL V3.5.3
พัฒนาโดย Ntnksai
โรงเรียนวัดแคทราย(บุญประชาสรรค์)

วิธีใช้งาน
1. เปิดไฟล์ index.html ด้วย Google Chrome, Microsoft Edge หรือ Safari รุ่นใหม่
2. เลือกประเภทการสุ่มและป้อนข้อมูลตามต้องการ
3. กดสร้างชุดข้อมูล แล้วกดปุ่มสุ่ม
4. เมื่อได้ผลลัพธ์ ให้กดปุ่มนำออกและบันทึกเพื่อเก็บผลไว้ในประวัติ
5. สามารถกดเต็มจอเพื่อแสดงผล และใช้ปุ่มสุ่ม/บันทึกในโหมดเต็มจอได้

การปรับปรุงใน V3.5.3
- ปรับเลย์เอาต์ให้เหมาะกับมือถือแนวตั้งและแนวนอน
- ปรับขนาดวงล้อและข้อความตามพื้นที่หน้าจอ
- เมื่อมีตัวเลือกจำนวนมาก จะแสดงเลขลำดับบนวงล้อและรายการเต็มในแถบเลื่อน
- ย้ายสถิติ จำนวนทั้งหมด คงเหลือ และรายการที่บันทึก เข้าไปอยู่ในกรอบผลลัพธ์
- เอาปุ่มยกเลิกผลออกจากหน้าผลลัพธ์
- ปรับปุ่มสุ่ม/หมุนวงล้อและปุ่มนำออกและบันทึกให้มีขนาดสอดคล้องกัน
- ยกเลิกข้อจำกัดจำนวนตัวเลือกของวงล้อ

หมายเหตุ
- ข้อมูลที่บันทึกอยู่ใน local storage ของเบราว์เซอร์และอุปกรณ์นั้น ๆ
- การเปิดไฟล์ HTML ในเครื่องไม่จำเป็นต้องเชื่อมต่ออินเทอร์เน็ต
- ควรสำรองข้อมูลชุดสำคัญด้วยการส่งออกตามเครื่องมือในโปรแกรม
