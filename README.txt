โปรแกรมสุ่ม V3.5 (Randomizer Tool)
พัฒนาโดย Ntnksai
โรงเรียนวัดแคทราย(บุญประชาสรรค์)

วิธีใช้งาน
1. เปิดไฟล์ index.html ด้วย Google Chrome, Microsoft Edge หรือ Safari รุ่นใหม่
2. เลือกประเภทการสุ่มจากเมนูด้านบน
3. กำหนดรายการหรือค่าที่ต้องการ แล้วกดสร้างชุดข้อมูล
4. กดปุ่มสุ่ม และบันทึกผลลัพธ์ตามต้องการ
5. บันทึกชุดข้อมูลไว้เพื่อเรียกใช้ซ้ำได้ในเบราว์เซอร์เครื่องเดิม

เครื่องมือ
- สุ่มตัวเลข
- สุ่มรายชื่อ
- สุ่มรายการ
- วงล้อสุ่ม (สูงสุด 40 ตัวเลือก)
- สุ่มเรียงลำดับรายการ
- สุ่มแบ่งกลุ่ม
- สุ่มคำตอบ 2 ตัวเลือก
- ลูกเต๋า

จัดการข้อมูล
- บันทึก / เรียกใช้ / ลบชุดข้อมูล (เก็บใน Local Storage ของเบราว์เซอร์)
- นำเข้า Excel .xlsx (ต้องใช้เบราว์เซอร์ที่รองรับ DecompressionStream), CSV, TXT และ TSV
- ส่งออกรายการและประวัติเป็น CSV UTF-8 ซึ่งเปิดด้วย Microsoft Excel ได้
- พิมพ์หรือบันทึกเป็น PDF ผ่านเมนูพิมพ์ของเบราว์เซอร์

หมายเหตุ
- โปรแกรมเป็นเว็บแอปหน้าเดียว ไม่ต้องติดตั้งเซิร์ฟเวอร์และไม่ส่งข้อมูลไปยังระบบภายนอก
- ข้อมูลที่บันทึกไว้จะอยู่ในเบราว์เซอร์และอุปกรณ์เดิม การล้างข้อมูลเว็บไซต์/เบราว์เซอร์อาจทำให้ข้อมูลหาย
- ไฟล์ .xlsx ใช้การอ่านด้วย API ของเบราว์เซอร์สมัยใหม่ หากอุปกรณ์ไม่รองรับ ให้นำไฟล์ Excel ไปบันทึกเป็น CSV UTF-8 แล้วนำเข้าแทน
- การนำเข้า Excel จะอ่านข้อมูลจากแผ่นงานแรก และใช้คอลัมน์ที่มีหัวข้อ เช่น รายการ, ชื่อ, รายชื่อ หรือคอลัมน์แรกที่พบข้อมูล
